# Фаза 1. Разведка макета

Какие кадры вообще верстать — и какие только выглядят кадрами.

## 1.1 Снять кадры

```
figma_sync(все ссылки задачи одним вызовом)
```

Один вызов на файл — дальше разбор идёт по снимку и в Figma не ходит. Лимит REST на Starter —
десять запросов в минуту, у места View/Collab двадцать в месяц.

## 1.2 Опознать кадры

```
figma_structure(канвас, depth: 1)            → что лежит на холсте
figma_export(kind: "render", scale: 0.5)     → опознать глазами
```

Чего ожидать:

- **Ссылка из задачи может указывать не на кадр.** `node-id` вёл на весь канвас в 2678 узлов.
- **Один экран бывает разложен на несколько кадров.** Мобильная версия жила в двух: `Mobile 1`
  (хиро…футер) и `Mobile` (секции, дорисованные позже). Свёрстан был бы только первый — половина
  страницы осталась бы без мобильной версии.
- **Рядом лежат служебные кадры.** `Перевод` — исходник текстов для переводчика. `Новые блоки` —
  секции, уже вмёрженные в основной макет. `блок 1` — хиро отдельно. Это не страницы.

## 1.3 Составить карту

Таблица: кадр → ширина → что это (страница, состояние, черновик, справочный материал) →
верстаем или нет.

## Гейт фазы

Карта кадров показана человеку и подтверждена. Кадр, про который непонятно «макет это или
черновик», — вопрос человеку, а не решение агента.
