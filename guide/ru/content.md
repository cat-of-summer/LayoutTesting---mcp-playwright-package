# Фаза 6. Контент

Тексты — в данные, артефакты переносов — вычистить, заглушки — опознать.

## Чек-лист

ВХОД: шрифты согласованы.
ШАГИ:
  1. figma_spec(кадр) → text — полные тексты и runs (смешанные кегли внутри строки).
  2. Тексты — в данные, один источник на все брейкпоинты.
  3. Вычистить пробелы-переносы из Figma (скриптом).
  4. Опознать заглушки списков; компонент работает при 0, 1 и N элементах.

## 1. Тексты в данные, не в разметку

Один источник на все брейкпоинты, плюс из него собирается сабсет шрифта.

## 2. Figma отдаёт переносы строк пробелами

В китайском и японском это рвёт слова посреди слова: `而地缘政 治压力` вместо `而地缘政治压力`.
Вычищать пробелы между иероглифами скриптом — в одном проекте таких оказалось 59. В кириллице и
латинице то же самое, но заметно меньше.

Полные тексты берутся из `figma_spec` (раздел `text`) или `figma_inspect` с `mode: "text"`:
остальные режимы режут строки многоточием.

## 3. Количество элементов в макете ≠ количество в жизни

Три карточки новостей и пагинация «01 … 10» — это заглушка ленты из тридцати. Компонент должен
работать при любом количестве, включая ноль и один. Проверяется это `layout_stress` со сценарием
`lists`.

## 4. Состояние — не данные

Раскрытая первая карточка слайдера в макете — это показанное состояние (`hover`, активный слайд),
а не признак «у этой карточки есть суммы». Данные о суммах — у всех карточек; раскрытие —
класс состояния (`swiper-slide-active`, `:hover`). Подменять поведение содержимым данных ради
совпадения высоты секции нельзя: высота сойдётся, поведение — нет.

## Гейт фазы

Тексты вынесены, артефакты переносов вычищены, известно, какие списки — заглушки.
