# Фаза 12. Проект целиком

Все ширины, эталоны, сборка — и уборка за собой.

## Чек-лист

ВХОД: каждая страница прошла гейт фазы 11.
ШАГИ:
  1. layout_stress(widths: полный ряд 320…1920) по каждой странице.
  2. visual_baselines — эталоны; дальше visual_compare.
  3. web_vitals / lighthouse.
  4. npm run build → dist на стенд → повторить проверки фазы 11 по собранному.
  5. browser_close всем сессиям, остановить dev-сервер, убрать разовые контейнеры.

## Сборка и проверки по собранному

```
npm run build   →   отдать dist   →   повторить проверки фазы 11
```

Дев-сервер и бандл — разные сборки, и это не формальность: CSS библиотек, подключённый из
клиентского скрипта, в dev виден, а в бандл не попадает; `allowedHosts` у preview берётся из
другого места конфига.

> Именно в билде вылезло, что плагин шрифтов падает на Windows при удалении дубля и валит весь
> билд ненулевым кодом. На dev-сервере этого не было видно вовсе.

Проверить в `dist`: нет неиспользованных ассетов, иконки собрались в спрайт, шрифты подключены,
размер разумный.

## Убрать за собой

- `browser_close` по всем открытым сессиям;
- разовые Docker-контейнеры убрать, dev-сервер остановить;
- временные файлы прогонов — `artifacts_clean`, если место кончилось.

## Гейт проекта

Прогон по всем ширинам чист, эталоны заведены, сборка проходит, проверки фазы 11 повторены по
`dist`.
