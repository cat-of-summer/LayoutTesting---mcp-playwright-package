## Сборка и проверки по собранному

```
npm run build   →   отдать dist   →   повторить проверки фазы 11
```

Дев-сервер и бандл — разные сборки, и это не формальность.

> Именно в билде вылезло, что плагин шрифтов падает на Windows при удалении дубля и валит весь
> билд ненулевым кодом. На dev-сервере этого не было видно вовсе.

Проверить в `dist`: нет неиспользованных ассетов, иконки собрались в спрайт, шрифты подключены,
размер разумный.

## Убрать за собой

- `browser_close` по всем открытым сессиям;
- разовые Docker-контейнеры убрать, dev-сервер остановить;
- временные файлы прогонов — `artifacts_clean`, если место кончилось.
