# Фаза 7. Договорённости с человеком

Вопросы, ответ на которые знает только человек. Задать до первой строки вёрстки.

Один вопрос дешевле переделки блока.

## Что спросить

- **Шрифты** — есть ли файлы коммерческого, чем заменять.
- **Объём анимаций** — всё из прототипа, часть, ничего.
- **Заглушки** — языковые версии и разделы, которых нет в макете.
- **Адаптив между кадрами** — fluid `clamp()` или фиксированные состояния.
- **Данные** — сколько элементов в реальном списке.
- **Спорные места макета** — противоречия, `drift`, явные ошибки дизайнера.
- **Контраст из палитры** — если низкий контраст идёт из брендовых цветов, менять их агент не
  вправе. Это решение человека.

## Чего не спрашивать

Того, что закрывается проверкой: прочитать код, выполнить запрос, посмотреть конфиг. Спрашивают
там, где ответ знает только человек: приоритеты, намерения, доступ, решения о рисках.

## Гейт фазы

Ответы получены.
