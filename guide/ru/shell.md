До страниц верстается то, что повторяется. Иначе одно и то же переделывается на каждой странице.

## Чек-лист

ШАГИ:
  1. Шапка, подвал, мобильное меню, модалки, UI-кит — по циклу фазы 10 каждый.
  2. Элемента нет в мобильном кадре (шапка, подвал) — он найден в файле на фазе 1; не «без шапки».

## Что сюда входит

Шапка, подвал, мобильное меню, модалки, UI-кит.

Мобильная шапка верстается и тогда, когда в мобильном кадре страницы её нет: отступ под неё в
кадре — сигнал, что она лежит отдельным кадром, и найти её — работа фазы 1. Один лендинг сдали
без мобильной шапки, хотя её макет был в файле: агент его не нашёл и предложил не верстать.

## Правило проброски классов

Компонент, принимающий `class` снаружи, обязан его домешивать, а не затирать:

```astro
// неверно — class из props затрёт собственный класс компонента
const { ...props } = Astro.props;
<a class="card" {...props}>

// верно
const { class: className, ...props } = Astro.props;
<a class:list={['card', className]} {...props}>
```
