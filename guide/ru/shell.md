## Что сюда входит

Шапка, подвал, мобильное меню, модалки, UI-кит.

## Правило проброски классов

Компонент, принимающий `class` снаружи, обязан его домешивать, а не затирать:

```astro
// неверно — class из props затрёт собственный класс компонента
const { ...props } = Astro.props;
<a class="card" {...props}>

// верно
const { class: className, ...props } = Astro.props;
<a class:list={['card', className]} {...props}>
```

> вылез в карточке новости: переданный `swiper-slide` терялся, слайдер поднимался с нулём слайдов
> и блокировал стрелки. На скриншоте это выглядело нормально; нашёл бы `interaction_audit` —
> стрелка попала бы в `silent`.
