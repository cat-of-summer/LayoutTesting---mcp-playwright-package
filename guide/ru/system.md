# Фаза 3. Дизайн-система

Токены, компоненты и брейкпоинты — до первого блока.

## 3.1 Токены

```
figma_tokens(все кадры)
```

Полезен тремя вещами:

- **частотность** — видно, что основное, а что разовое;
- **`unbound`** — сколько раз значение вбито литералом при живой переменной Figma; это и есть
  работа, которую выносят в токен;
- готовые **`clamp()`** по парам кадров разной ширины.

Токеном становится значение, привязанное к переменной Figma, встречающееся не один раз или уже
существующее в проекте. Разовый отступ токеном не становится. То, что меняется по варианту или
состоянию, — переменная компонента (`.btn{--btn-bg}` → `.btn--ghost{--btn-bg:…}`), а не новый
глобальный токен.

> **Главная ловушка.** `figma_tokens` — это словарь файла, а не свойства узла. Четыре бага подряд
> (линия 1px, полоса 10px, цвет `rgba(0,0,0,.8)`, тире 2px) — значения, взятые из частотной
> сводки «по смыслу». Все четыре мимо. См. правило 1 в разделе `rules`.

## 3.2 Компоненты

```
figma_components(все кадры)
```

Сводит инстансы одного компонента в блок с модификаторами из свойств варианта. Непривязанные
блоки одинакового состава — тоже один блок: цвет, радиус, отступы и кегль становятся осями
модификаторов, а не поводом завести второй класс. Разовый элемент компонентом не делают.

`drift` — расхождения в пару пикселей или полтона внутри одного компонента. Это расхождение
**в макете**: сводят к одному значению, а не переносят в вёрстку.

## 3.3 Брейкпоинты

```
figma_breakpoints(кадры одного экрана разной ширины)
```

Показывает, что тот же элемент, что изменилось (кегли, отступы, направление раскладки), что
исчезло, чем заменено, где разошёлся порядок чтения. Линейно меняющиеся значения отдаёт готовым
`clamp()`.

Правило: mobile-first. Линейно меняющееся — `clamp()`, скачком — media-запрос. Замена элемента
(select на десктопе, иконка на мобильной) — два состояния одного блока, а не два блока.

Точка перелома **проверяется прогоном по ширинам** (`layout_stress`, сценарий `widths`), а не
назначается по числу из макета.

## Гейт фазы

Заведены переменные и UI-кит: кнопки, ссылки, инпуты, карточки, таблицы. Ни одно значение из
`figma_tokens` не попало в вёрстку без подтверждения на конкретном узле.
