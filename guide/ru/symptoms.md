# Симптом → инструмент

Таблица быстрого выбора: с чем пришли и чем это смотреть.

## Макет

| Симптом | Чем смотреть |
|---|---|
| Не знаю, какие кадры верстать | `figma_structure` с `depth: 1` и `figma_export` с `kind: "render"` |
| Разбираю блок и не знаю, с чего начать | `figma_spec` — дерево, краска, тексты и ассеты одним вызовом |
| Не знаю цвет, обводку, радиус, прозрачность узла | `figma_inspect` с `mode: "outline"` — краска в фигурных скобках |
| Текст обрезан многоточием | `figma_inspect` с `mode: "text"` или раздел `text` у `figma_spec` |
| Не знаю, что делает элемент | `figma_behavior`, `figma_comments` |
| Не знаю, во что переключается вариант | `figma_sync` по ссылке из `notSynced` |
| Не знаю, что отсюда скачивать | раздел `assets` у `figma_spec`: `plan` — готовые списки для экспорта |
| Нужна иконка | `figma_export` с `kind: "svg"` по id узла |
| Нужно фото | `figma_export` с `kind: "image"` и `scale: 2` |
| Фигура с картинкой-заливкой, обрезкой, поворотом | `figma_export` с `kind: "render"` |
| Экспорт отказал: «no visible layers» | скрытый слой — повторить с показом скрытых |
| Тяжёлый PNG | `image_convert` в WebP |

## Сверка

| Симптом | Чем смотреть |
|---|---|
| Совпадают ли тексты и кегли | `figma_compare` с `mode: "semantic"` |
| Совпадают ли фоны, рамки, линии, радиусы | раздел `paint` того же отчёта |
| Узел «не найден» в `paint` | смотреть, в какой корзине: `shifted` — уехал, и видно куда; `notFound` — не нашёлся нигде |

## Вёрстка

| Симптом | Чем смотреть |
|---|---|
| Правка не применилась | `computed_styles` → `matched_rules` → перезапуск dev-сервера |
| Элемента не видно, чем-то накрыт | `element_layers` |
| Поехало на узком экране | `layout_stress` со сценарием `widths` |
| Ломается на длинном тексте или большом списке | `layout_stress` |
| Работает ли слайдер, аккордеон, кнопка | `interaction_audit` в сессии с `animations: "allow"` |
| Честная ли анимация | он же: `timing.smooth` и `durationMs` |
| Что вообще не так со страницей | `audit` — самый дешёвый первый шаг |
| Не сломал ли я то, что работало | `visual_baselines` → `visual_compare` |
