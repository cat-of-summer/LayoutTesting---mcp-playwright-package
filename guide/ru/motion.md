# Фаза 8. Анимации и состояния

Направление перехода, его параметры и полный список состояний каждого элемента.

## 8.1 Снять параметры

```
figma_behavior                        → триггер, длительность, easing, группировка
figma_sync(цели связей из notSynced)  → во что переключается вариант
figma_spec(цель)                      → краска целевого состояния
```

Связь даёт «откуда → куда». Чтобы понять направление, снять **оба** состояния.

> **Как здесь ошибаются.** Связь вела от дефолта хиро к варианту с `rgba(0,0,0,0.4)`. Была
> посмотрена только цель — и сделан вывод, что вуаль уходит. В дефолте было `{op0.2}` поверх
> `rgba(0,0,0,0.1)` — почти прозрачная плёнка, и вуаль **приходит**. Направление восстановилось,
> только когда сняли оба состояния.

## 8.2 Состояния элементов

Отдельно выписать для каждого интерактивного элемента: `hover`, `focus-visible`, `active`,
`disabled`, `error`, состояние загрузки, пустое состояние. В макете это обычно варианты
компонента — берутся из `figma_components` и `figma_behavior`.

Пропущенное состояние заметить труднее всего: на макете его просто нет, и в сверке оно не
всплывёт.

## 8.3 Обязательное

Любая анимация уважает `prefers-reduced-motion`.

## Гейт фазы

Для каждой анимации известны триггер, обе точки, длительность и кривая; для каждого элемента —
список состояний.
